# Astronomicum Caesareum Volvelle

A digital restoration of a historical astronomical instrument from Peter Apian's *Astronomicum Caesareum* (1540).

## 🌌 About the Project
This project aims to recreate the experience of interacting with a 16th-century volvelle (rotating paper disk) as a functional digital tool. Rather than a simple UI, it is a "digital facsimile" that allows users to manipulate layers, pointers, and scales to understand how Renaissance astronomers performed calculations.

### Current Implementation: The Dragon Volvelle (*De Nodo Draconis*)
The MVP focuses on the Dragon Volvelle, used to calculate the lunar nodes—the points where the Moon's orbit intersects the ecliptic.

## 🛠️ Technical Stack
- **React 18** & **TypeScript**
- **Vite** (Build tool)
- **Tailwind CSS** (Styling)
- **SVG** (Vector graphics for precision rotation)
- **Lucide React** (Icons)

## 📖 Features
- **Facsimile Mode**: A pure visual experience emphasizing the aesthetic of a 16th-century book.
- **Study Mode**: An annotated view that explains the purpose of each disk, pointer, and marking.
- **Precise Rotation**: SVG-based coordinate system ensuring perfect center alignment.
- **Responsive Design**: Optimized for both desktop study and mobile interaction.

## 📜 Historical Context
The *Astronomicum Caesareum* is one of the most visually stunning astronomical works of the Renaissance. By incorporating movable parts directly into the printed page, Apian transformed a book into a tactile calculator.
